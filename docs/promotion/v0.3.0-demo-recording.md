# binquery v0.3.0 demo recording

This production note records the verified no-footage demo without presenting it
as a semantic-quality benchmark.

## Verified baseline

Verified locally on 2026-08-26 with the repository's `.venv`:

- `binquery demo` generated one 30-second lavfi video.
- It split the video into 3 clips and indexed 9 stills.
- `doctor` reported `can_query: yes`.
- The query returned 3 ranked results and wrote `query.json`.
- The first run took 318.60 seconds in this environment, including a roughly
  590 MB OpenCLIP model download.
- A second run with the same model cache took 11.19 seconds.

These timings describe one run on one machine. Do not present them as general
performance claims.

## Recording preparation

1. Finish the first model download before recording.
2. Disable notifications and close unrelated windows.
3. Use a clean terminal profile with a large font and no secrets in the prompt.
4. Record a terminal window, not the whole desktop.
5. Choose a new output path. `binquery demo --out` will not overwrite a
   non-empty directory.
6. Run one preflight with a disposable output path to confirm the model cache
   and ffmpeg are available. Use a different new path for the recorded run.

Suggested preflight command:

```bash
binquery demo --out /tmp/binquery-demo-preflight
```

Suggested recording command:

```bash
binquery demo --out /tmp/binquery-demo-recording
```

If that path already exists, choose another new path instead of deleting it
during the recording.
